# Tic Tac Toe Desktop Game

A modern, user-friendly Tic Tac Toe game built with Python and Tkinter.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-blue?style=for-the-badge&logo=github)](https://github.com/AidenDaysGrace/Tic-tac-toe.git)

## Features

- 🎮 **Two-player gameplay** - Play with a friend on the same computer
- 🎨 **Modern UI** - Clean, dark theme with hover effects
- 🏆 **Score tracking** - Keep track of wins for both players
- ✨ **Visual feedback** - Winning combinations are highlighted
- 🔄 **Easy reset** - Start a new game anytime with the "New Game" button
- 💻 **Cross-platform** - Works on Windows, macOS, and Linux

## Requirements

- Python 3.x (Python 3.6 or higher recommended)
- Tkinter (usually comes pre-installed with Python)

## How to Run

1. **Make sure Python is installed** on your system
2. **Open a terminal/command prompt** in the game directory
3. **Run the game** with one of these commands:

```bash
python tic_tac_toe.py
```

or

```bash
python3 tic_tac_toe.py
```

## How to Play

1. **Start the game** - Player X goes first
2. **Take turns** - Click on any empty square to place your mark (X or O)
3. **Win conditions** - Get three of your marks in a row (horizontally, vertically, or diagonally)
4. **Game over** - When someone wins or the board is full (tie)
5. **New game** - Click "New Game" to start over

## Game Controls

- **Mouse click** - Place your mark on the board
- **New Game button** - Reset the game and start over
- **Close window** - Exit the game

## Troubleshooting

If you get an error about Tkinter not being found:
- **Windows**: Tkinter should be included with Python installation
- **macOS**: Install Python from python.org or use Homebrew
- **Linux**: Install with `sudo apt-get install python3-tk` (Ubuntu/Debian)
